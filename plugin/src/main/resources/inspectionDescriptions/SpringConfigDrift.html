Highlights the results of the most recent Spring Config Drift analysis in the editor: keys missing from an environment, type or structure mismatches between profiles, exposed credentials, unresolved ${...} references, and disagreements with spring-configuration-metadata.json.

Because drift is a property of several files together rather than of the file being edited, this inspection does not compute anything on its own — it displays the last completed project-wide analysis. The analysis re-runs automatically shortly after a configuration file changes, and can be triggered at any time from Tools | Analyze Spring Config Drift. Highlights therefore reflect the last analysed state of the files, not unsaved edits.

Use Alt+Enter on a highlight to dismiss an individual finding. Dismissed findings are listed in the Suppressed tab of the Config Drift tool window and can be restored from there. Disabling this inspection hides all highlights but leaves the tool window and report export unaffected.

Exposed credentials are the one exception: they cannot be dismissed. The remedy is to move the value out of the file — for example to ${DB_PASSWORD} — rather than to agree to stop being warned about it.
